# 8-bit ALU Physical Design

Gate-level netlist generated by Yosys of an 8-bit ALU taken through floorplan, placement and routing
in OpenROAD using the ORFS sky130hd platform, carried out in WSL terminal.
Text editor used for RTL: nano

## Files
- alu8.v: RTL
- alu8_netlist.v: gate-level netlist (sky130hd)
- tb_alu8.v: testbench
- run.tcl: OpenROAD script
- alu_gds: jpg of the final gds design 

## Flow
Load LEF/liberty, read_verilog, link_design, floorplan, pdngen, placement, routing.
